# Restaurant Review Analysis Using LLM and Prompt Engineering

## Project Overview
Restaurant Review Analysis is an AI-powered project that uses Large Language Models (LLMs) and prompt engineering to analyze customer reviews and understand their dining experiences. The project uses the Mistral-7B-Instruct model to identify customer sentiment, analyze feedback on food quality, service, and ambience, extract liked and disliked features, and generate personalized responses to customer reviews.

## Objectives
- Classify customer reviews into Positive, Negative, and Neutral sentiments.
- Perform aspect-based sentiment analysis for food quality, service, and ambience.
- Extract specific features that customers liked or disliked.
- Generate polite and empathetic responses to customer feedback.
- Provide actionable insights to help restaurants improve customer satisfaction.

## Technologies Used
- Python
- Pandas
- Hugging Face Transformers
- Mistral-7B-Instruct
- Prompt Engineering
- JSON Processing
- Google Colab

## Key Features
- **Overall Sentiment Analysis:** Identifies the overall sentiment of each customer review.
- **Aspect-Based Sentiment Analysis:** Evaluates sentiment related to food quality, service, and ambience.
- **Feature Extraction:** Identifies specific positive and negative feedback, such as food taste, waiting time, staff behaviour, and lighting.
- **Automated Customer Responses:** Generates personalized responses based on customer feedback and sentiment.
- **Structured Output:** Uses JSON-formatted responses for organized analysis and easy data processing.

## Business Impact
This project helps restaurants and food aggregators analyze customer feedback efficiently, identify areas that need improvement, understand customer preferences, and enhance the overall dining experience.
